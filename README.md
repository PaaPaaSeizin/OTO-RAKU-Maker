[推奨環境:Windows(Chrome)]

全体概要

このアプリケーションは、ブラウザ上で動作する音MAD（音声素材を編集してBGMに合わせた動画を作る）制作環境です。主な特徴：

• 複数の楽器（トラック）を持ち、各楽器に音素材を割り当て可能

• ピアノロール形式のグリッド（音マップ）に、ピースと呼ばれるブロックを配置して音符のタイミングと長さを指定

• ピースはドラッグで移動、端をドラッグで長さ変更、右クリックでメニュー（削除、コピー、伸び切替）

• BPMや音量、ピッチ調整、ミュート/ソロ、磁石機能（グリッドにスナップ）あり

• プロジェクトの保存/読み込み（.otomap形式）、WAV書き出し（BGMあり/なし）

• プラグインシステム（.jsファイルを動的に読み込んで機能拡張可能）

• キーボードショートカット（Ctrl+Z/Y アンドゥ/リドゥ、Ctrl+C/V コピペ、Delete削除、Space再生/停止、Home/End 先頭/末尾、←→で再生ヘッド移動など）

• 履歴（Undo/Redo）機能（最大50ステップ）

以下、機能ごとに詳細説明。

1. 楽器パネル（左サイドバー）

• 楽器の追加：「+ 楽器を追加」ボタンで新しい楽器を作成。IDは自動採番。

• 楽器カード：各楽器は以下のコントロールを持つ

• 楽器名の編集（テキストフィールド）

• 音量スライダー（0～100）

• ピッチ調整スライダー（-200～200セント）。中央が0（調整なし）。ドの音に近づくとUIのバー色が変わる（実装あり？要確認）。

• MUTEボタン：その楽器をミュート

• SOLOボタン：その楽器だけを再生（他はミュート）

• ファイル選択（音素材の読み込み：WAV/MP3）

• テスト再生ボタン：現在のピッチで素材を再生（連打防止トグル式）

• 楽器の選択：楽器カードをクリックすると選択状態（ハイライト）になり、その楽器のピースだけが右の音マップに表示される。

• 楽器の削除：ゴミ箱ボタンで楽器とそれに属する全てのピースを削除（履歴対象）。

2. BGMトラック

左パネルの下部にBGMトラック専用セクションあり。

• BGM用の音素材を読み込み、音量調整、ミュート、テスト再生が可能。

• プロジェクト保存・WAV書き出し時にBGMを含める/含めない選択ができる（ツールバーに「WAV書き出し (BGMオフ)」ボタンあり）。

3. 音マップ（メイングリッド）

• 縦軸：音階（ド～シの2オクターブ、24音階、日本語表記）。一番下が低音（ド¹）、一番上が高音（シ²）。MIDIファイル読み込み時の拡張機能で72音階にも対応可能（別途プラグイン）。

• 横軸：時間方向のグリッド。初期32拍（BEATS=32）、ピースを置くにつれて自動拡張。

• ピース：各楽器の音素材の断片。グリッドセルに矩形として描画。

• 色：選択中の楽器のピースだけ表示。選択されているピースは青系、通常はオレンジ系。

• マーク：伸び切替モードが速度変更なら「⚡」、元の長さなら「◯」。

• 分割されたピースには「✂」マーク（startOffset/endOffsetを持つピース）

• 操作

• グリッドをクリック：選択中の楽器で長さ1のピースを作成（磁石ONなら整数拍にスナップ、OFFなら64分精度で自由位置）。

• Ctrl+クリック：複数選択のトグル。

• ピース上で左クリック（Ctrlなし）：そのピースだけを選択状態に。

• ピースの中央をドラッグ：移動（磁石ONなら整数拍、OFFなら64分精度で自由移動）。縦方向も移動可能。

• ピースの左右端をドラッグ：長さ変更（リサイズ）。端の検出閾値は20ピクセル。磁石ONなら整数拍スナップ。

• 右クリック：選択されている全てのピースに対するコンテキストメニューを表示（削除、コピー、伸び切替、分割、貼り付け）。分割は常に64分音符単位で正確にカット。

• 磁石機能：ツールバーの「🧲 磁石 (64分) ON」ボタンでON/OFF切り替え。ON時はピースの移動・新規作成・リサイズが整数拍（4分音符単位）でスナップ。分割は常に64分精度（磁石の影響を受けない）。

4. ツールバー（上部）

• BPM入力（数値）

• 磁石トグル（前述）

• 再生/停止ボタン（スペースキーでも可）

• WAV書き出し（全トラック＋BGMをまとめたWAVをダウンロード）

• WAV書き出し (BGMオフ)

• プロジェクト保存（.otomapファイルとしてJSON保存）

• 読み込み（.otomapファイルを選択して復元）

• 選択バッジ（複数選択時に選択個数を表示）

• 時間表示（現在の再生位置/全体長さ、mm:ss.xx形式）

5. ピースの詳細機能

• 伸び切替：右クリックメニューから「伸び切替」を選択すると、そのピースのモードが切り替わる。

• 速度変更モード：ピースの長さに合わせて素材の再生速度を変更（ピッチも変わる）。

• 元の長さモード：素材本来の長さで再生。ピースの長さはあくまで範囲指定（短ければ途中で切れ、長ければ無音部分が続く）。デフォルトはこのモード。

• 分割：ピースを任意の拍位置で2つに分割。分割点は常に64分音符単位でスナップし、分割後の両ピースは元の素材内の開始オフセットと終了オフセットを持つ。これにより、分割後の再生範囲が正確。

• コピー＆ペースト：ピースを右クリック→コピー、その後どこかで右クリック→貼り付け。貼り付け時はマウスカーソルの位置（磁石ONなら整数拍スナップ）に貼り付けられ、貼り付けたピースは自動的に選択状態になる。

• 複数選択：Ctrl+クリックで複数ピースを選択。選択状態のピースは青枠で表示。まとめて移動（ドラッグ）、削除、コピー、伸び切替が可能。

6. 再生/停止とタイムライン

• 再生ヘッド（赤い縦線）が現在の再生位置を示す。

• 再生ヘッドはドラッグで移動可能（再生中は停止する）。

• キーボードの←→キーで再生ヘッドを1拍移動（Ctrl同時押しで0.25拍移動）。

• Homeキーで先頭（0拍）、Endキーで末尾。

• 再生中はヘッドが自動進行し、時間表示も更新。

• 再生開始位置は現在のヘッド位置からスタート（途中からの再生が可能）。

• 停止時はヘッド位置がそのまま残る。

7. 履歴（Undo/Redo）

• 主要な操作（ピース追加、削除、移動、リサイズ、分割、貼り付け、楽器の追加/削除など）は履歴に保存。

• Ctrl+Zで元に戻す、Ctrl+Yでやり直し。

• 履歴数は最大50ステップ。

8. プロジェクトの保存と読み込み

• 保存：現在のプロジェクト（BPM、楽器構成、ピース配置、選択状態など）をJSON形式で.otomapファイルとしてダウンロード。音素材のバイナリは保存しない（ファイルパスではなくbufferオブジェクトは保存されないため、再読み込み時は音素材の再アップロードが必要）。

• 読み込み：.otomapファイルを選択すると、楽器リストとピースデータなどが復元される。音素材は別途読み込む必要がある。

9. WAV書き出し

• OfflineAudioContextを使用して全楽器のピースとBGMをミックスし、44.1kHzステレオWAVファイルを生成。

• ピースの元の長さモードでは素材本来の長さに従い、速度変更モードではピース長に合わせて再生レートを変更して書き出し。

• BGMを含める場合と含めない場合の2種類。

10. プラグインシステム

• ヘッダーの「プラグイン管理」ボタンでモーダルを開く。

• 登録済みプラグインの一覧表示、削除、設定（プラグインが提供するUI）が可能。

• 「JSファイルから追加」ボタンで.jsファイルを選択して動的に読み込む。

• プラグインはグローバルオブジェクトwindow.OTOPLUGIN.registerPluginを使って登録。manifestにname, version, setup, destroy, settingsUIを含む。

• サンプルとして「使い方ガイド」プラグインが内蔵。ツールバーに「📖使い方」ボタンを追加する（YouTubeの楽曲に飛ぶ）。

11. キーボードショートカット一覧

• Ctrl+S: プロジェクト保存

• Ctrl+Z: Undo

• Ctrl+Y: Redo

• Ctrl+A: 現在の楽器の全ピースを選択

• Delete: 選択中のピースを削除

• Space: 再生/停止

• Home: 再生ヘッドを先頭へ

• End: 再生ヘッドを末尾へ

• ← →: 再生ヘッドを左右へ移動（1拍）

• Ctrl+← →: 0.25拍移動

• Esc: 選択解除

• （また、上下左右キーは選択中のピースを移動させる：ArrowUp/Downで音階移動、ArrowLeft/Rightで時間移動）

12. その他のUI/UX

• 右クリックメニュー（ピース上、空き地）が表示される。

• グリッドの下に各拍の秒数を表示。

• キャンバス上のマウスカーソルは状況に応じて変化（crosshair, grab, ew-resize）。

• ツールバーのボタンやメニューはダークテーマで統一。

• ヘッダーにプロジェクト名入力、保存、読み込み、プラグイン管理ボタン。

技術的な補足

• オーディオ処理はWeb Audio APIを使用。

• ピースのstartOffsetとendOffsetで素材内の切り出し範囲を管理。分割やリサイズで適切に更新される。

• タイミングの基本単位は「拍（beat）」。1拍 = 60 / BPM 秒。

• 磁石OFF時は64分音符（1/64拍）精度で浮動小数点位置を保持。

• WAV書き出しのバッファ生成はbufferToWav関数で、全チャンネルを正しくインターリーブしている。

• 履歴の保存はsaveToHistory()、復元はrestoreState()。
